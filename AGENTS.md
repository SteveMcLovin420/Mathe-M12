# Zusammenarbeit in diesem Repository

- Der Nutzer möchte Änderungen aus diesem Chat nach Umsetzung und Prüfung
  direkt auf GitHub sehen. Änderungen committen und auf `origin/main` pushen,
  sofern kein späterer Auftrag etwas anderes verlangt. Nicht nur lokal belassen.
- Bei parallelen Änderungen auf GitHub zuerst fetchen und die Änderungen
  integrieren. Kein Force-Push. Nicht zu diesem Auftrag gehörende lokale
  Änderungen nicht ohne Prüfung in den Commit übernehmen.
- Alle vier Dokumentordner eigenständig nutzbar halten. Für Quarto-HTML
  keine zusätzliche R- oder Python-Installation voraussetzen.
